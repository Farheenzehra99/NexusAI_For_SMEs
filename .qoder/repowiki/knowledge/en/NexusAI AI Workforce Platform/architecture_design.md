The project is a monorepo with two top-level application directories: `backend/` (FastAPI) and `frontend/` (Next.js 14 App Router). The backend follows a layered agent architecture where each AI agent is split across three files: `app/services/<domain>.py` (deterministic calculations), `app/services/llm.py` (optional LLM narration), and `app/agents/<domain>.py` (orchestration + registration). The agent base class (`app/agents/base.py`) defines a registry pattern — each agent module calls `register_agent()` at import time, triggered by `main.py` importing the agents package. The CEO orchestration service (`app/services/ceo.py`) implements a Route → Gather → Synthesize pipeline: keyword-based routing (supporting English, Urdu script, and Roman Urdu) selects which domain agents to consult, the BI snapshot (`app/services/bi.py`) aggregates all four domain snapshots into a single `BIFacts` object with a computed Health Score, and fixed synthesis rules produce `KeyFinding`, `RootCause`, and `RecommendedAction` objects. The database layer uses SQLAlchemy 2.0 declarative models with SQLite (no Alembic — tables are created on startup via `Base.metadata.create_all()`). The `Business` model is the tenant root with 10 related tables. Authentication uses bcrypt + JWT via FastAPI dependencies. The frontend wraps all pages in a `Sidebar` layout component with navigation, auth state, and a workforce activity indicator. API communication flows through a typed `fetchApi<T>()` client in `frontend/lib/api.ts` with AbortController timeouts and JWT injection from localStorage.

No single-command setup required. Backend: `cd backend`, create a virtual environment, `pip install -r requirements.txt`, copy `.env.example` to `.env`, run `python seed.py` to populate demo data, then `uvicorn app.main:app --reload --port 8000`. Frontend: `cd frontend`, `npm install`, `npm run dev` (requires `NEXT_PUBLIC_API_URL=http://localhost:8000` in `.env.local`). The Google Gemini API key is optional — all agents work without it using deterministic fallback templates.
